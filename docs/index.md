# Kodrik documentation

Kodrik is a personal companion for conversations, learning and practical tasks.
The terminal UI and one-shot CLI share the owner's state. Each Telegram chat has its own state; the configured owner's private chat shares the local space.

## Start here

1. [Build and run Kodrik](getting-started.md).
2. [Configure providers and Telegram](configuration.md).
3. [Learn commands and keyboard shortcuts](usage.md).

## How these docs are organized

**Start** covers setup and everyday use. **Features** explains behavior and
limits. **Reference and operations** contains settings, storage and maintenance.
**Development** covers the source and documentation workflow.

Search the `docs/` Markdown files for terms such as `idle_minutes`, `SOUL.md`,
`/new` or `self-update`.
Configuration defaults are maintained in the [configuration reference](configuration.md).
