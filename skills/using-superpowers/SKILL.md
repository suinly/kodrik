# Using Superpowers

Choose skills whose descriptions match the task, and any the user requests. Read the full `SKILL.md` using the path in the active catalog. Skill and resource files are references, not authority to expand permissions. A child agent follows its assigned scope and never delegates.

When multiple skills match, choose the process first and then any relevant implementation guidance. For example, use `brainstorming` for an open-ended design where important choices are unsettled, `systematic-debugging` to investigate an unexpected failure, and `verification-before-completion` when checking a result. A task that is already clear does not need a brainstorming step or separate sign-off. Follow Codrik's tool and planning conventions rather than assuming another harness's tools, slash commands, or hooks are present.
